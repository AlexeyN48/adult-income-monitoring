# Adult Income: стенд мониторинга ML

Учебный проект для подготовки и последующего мониторинга модели CatBoost на датасете UCI Adult Income. Целевой сценарий — локально показать дрейф входных признаков и целевого класса, аудит метрик по `sex`, качество модели и срабатывание правил Prometheus.

## Состояние

Сейчас подготовлен только каркас проекта: настройки упаковки, пример конфигурации, пустые каталоги для будущих данных и артефактов и минимальный импортируемый Python-пакет. Загрузка Adult, обучение CatBoost, сценарии мониторинга, отчёты Evidently, экспорт метрик, Prometheus и Docker Compose ещё не реализованы. Команд запуска модели пока нет.

Полный план этапов и критериев находится в [`PROJECT_PLAN.md`](PROJECT_PLAN.md).

## Требования и зависимости

Проверенное локальное окружение на этапе каркаса: CPython 3.12.10 (64-bit) и pip 26.1. Docker CLI 29.4.0 доступен, но `docker info` завершился с отказом доступа к Docker API (`dockerDesktopLinuxEngine`), поэтому работа демона не подтверждена. Выбран CPython 3.12; CatBoost требует CPython и 64-битную сборку. Для проекта зафиксированы прямые зависимости CatBoost 1.2.10, Evidently 0.7.23, pandas 2.3.3 и PyYAML 6.0.3. Выполнен импорт каркасного пакета и разбор `pyproject.toml`; ML-зависимости не устанавливались и их импорт не проверялся. Совместимость выбранных ML-версий обоснована опубликованными метаданными и документацией, но не исполнением проекта.

Создать виртуальное окружение и установить пакет можно командами:

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
```

Перед созданием окружения убедитесь, что `python --version` показывает Python 3.12. В проверенном окружении команда `python` работает, а launcher `py -3.12` не находит установленный Python. Если активация PowerShell недоступна, вызывайте интерпретатор напрямую: `.\.venv\Scripts\python.exe -m pip install -e .`.

Источники выбранных версий: [CatBoost 1.2.10](https://pypi.org/project/catboost/1.2.10/), [Evidently 0.7.23](https://pypi.org/project/evidently/0.7.23/), [pandas 2.3.3](https://pypi.org/project/pandas/2.3.3/), [PyYAML 6.0.3](https://pypi.org/project/PyYAML/6.0.3/). Полная установка и проверка совместного выполнения остаются задачей следующих блоков; транзитивные зависимости пока не зафиксированы lock-файлом.

Чтобы проверить только пакет каркаса без тяжёлых ML-зависимостей:

```powershell
python -m pip install -e . --no-deps
python -c "import adult_monitoring; print(adult_monitoring.__version__)"
```

## Конфигурация и структура

Пример будущих настроек находится в [`configs/example.yaml`](configs/example.yaml). Это только образец параметров: сейчас приложение его не читает.

- `src/adult_monitoring/` — Python-пакет.
- `configs/` — конфигурационные файлы.
- `data/raw/`, `data/interim/`, `data/processed/` — будущие этапы работы с данными.
- `models/` — сохранённые модели.
- `reports/` — будущие отчёты.

Датасеты, модели, виртуальные окружения, кэш и генерируемые результаты исключены из Git. Источник данных — [UCI Adult](https://archive.ics.uci.edu/dataset/2/adult), лицензия CC BY 4.0; атрибуция будет добавлена в блоке подготовки данных.
